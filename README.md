# BLACKED Fusion 2.2 — Standalone Demo

## New in this version
- Separate top navigation tabs for **Innerwear**, **Wellness 18+**, **Boyfriend**, and **Fit Studio**.
- Wellness has its own age self-attestation gate, pathways for Her/Him/Couples/Learn & Relax, a goal finder, and reset.
- Boyfriend has date planning, tone-based message ideas, conversation prompts, and boundary/consent guidance.
- Innerwear has functional search/category filtering and local saved styles.
- Fit Studio has local-only notes with clear controls.
- Responsive mobile layout and accessible labels/live result regions.

## Run it
Open `index.html` in a modern browser. This standalone package does not require npm, a server, or external images.

## Limitations
This is a functional front-end prototype. It does not connect to live products, payments, bookings, real companion services, medical advice, user accounts, or a backend. Age checks are self-attestation only. Saved styles and fit notes use browser local storage. This demo does not bundle the original image library or all 43 original catalog/reference entries from the GitHub repositories; those assets should be merged in a later full integration build.
